VisionClear AI – De-Smoking and De-Hazing System

📌 Project Overview

VisionClear AI is an AI-based image enhancement system designed to improve the visual quality of hazy and smoke-affected images.

The system uses image processing and deep learning techniques to recover image details, improve visibility, and enhance overall image clarity.

🎯 Objectives
	•	Reduce haze and smoke effects from images.
	•	Improve image visibility and clarity.
	•	Recover important image details.
	•	Analyse image quality before and after enhancement.
	•	Generate reports of image enhancement results.

🛠️ Technologies Used
	•	Python
	•	Streamlit
	•	Deep Learning
	•	Image Processing
	•	NumPy
	•	Pandas
	•	Plotly

✨ Key Features
	•	AI-based image de-hazing.
	•	Image recovery and enhancement.
	•	Clarity gain calculation.
	•	Image processing history.
	•	Database integration.
	•	PDF report generation.
	•	Interactive dashboard.
